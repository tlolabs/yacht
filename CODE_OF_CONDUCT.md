# Code of Conduct

YACHT adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The linked version is the governing text for participation in this project's community spaces and for anyone representing the project.

Thomas Lothian is responsible for moderation and enforcement. Please report conduct concerns privately to the maintainer; a dedicated public reporting email is **TBD**. Do not post a sensitive report in a public issue. Reports will be considered fairly, with care for the reporter's privacy. Moderation may include a correction, warning, temporary restriction, or permanent removal, following the Covenant's community impact guidance.

The Contributor Covenant is provided by the Organization for Ethical Source. See its [attribution and translations](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
