# Support

- **Bugs:** Open a [GitHub Issue](https://github.com/tlolabs/yacht/issues/new/choose) with a reproducible example and platform/version.
- **Feature requests:** Open a GitHub Issue describing the workflow and expected behavior.
- **Usage questions:** Use GitHub Issues after checking the [README](README.md) and [build guide](docs/BUILDING.md).
- **Security vulnerabilities:** Follow [SECURITY.md](SECURITY.md); do not put sensitive details in a public issue.
