# Security policy

## Supported versions

Security fixes target the latest stable release and current `main`. Older releases may receive a fix at the maintainer's discretion; they are not guaranteed support. See [GitHub Releases](https://github.com/tlolabs/yacht/releases) for the latest version.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/tlolabs/yacht/security/advisories/new), which was confirmed enabled on 2026-09-24. Please do not file a public issue or include exploit details in a public discussion before a fix or coordinated disclosure. Public security email: **TBD**. If private reporting becomes unavailable, contact Thomas Lothian through a private GitHub channel and avoid posting sensitive details publicly.

Include the affected version/platform, a reproducible description, impact, and any proof of concept that can be shared safely. Thomas Lothian will triage the report, coordinate a fix and disclosure timeline with the reporter, and publish a release and advisory when appropriate. Response time is best effort; no response deadline is promised.

Official fixes are delivered through [GitHub Releases](https://github.com/tlolabs/yacht/releases). Verify downloaded artifacts using the release's checksums and signing information. See the [code signing policy](CODE_SIGNING_POLICY.md).
