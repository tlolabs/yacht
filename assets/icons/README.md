# YACHT icon

Original vector artwork for this repository, covered by the root GPL-3.0 license.
`YACHT.svg` is the source of truth. `YACHT.png` is the 1024-pixel preview;
`YACHT.icns` contains macOS sizes and `YACHT.ico` contains Windows sizes.

Run `./script/generate_icons.sh` on macOS with librsvg and ImageMagick to regenerate.
The same icon is used for both architectures on macOS, Windows and Linux.
